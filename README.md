# Project42

## What: 仕組みを作るプロジェクト

42Tokyoコミュニティの中で、**一度作れば自走する仕組み**を生み出す活動。利益ではなく、継続的な価値を目的とする。

## Why: 起業を“体感”する場をつくる

いきなり大きく始めるのではなく、**小さな挑戦・失敗・成功を通して「仕組みで解決する感覚」**を身につける。

## Who: 挑戦したいけど迷っている人へ

* 起業や仕組みづくりに興味がある
* アイデアはあるが何から始めるか分からない
* 同じ志を持つ仲間と試してみたい

> スキルよりも、行動と好奇心が大事。

## When: 無理なく続けられるペースで

42Tokyo在学中、**日常の延長線上で**進められるリズムで挑戦できる。

## Where: 42Tokyoの中で

キャンパスでもオンラインでもOK。成果は42Tokyo全体に還元される。

> 自分たちの作った仕組みが、仲間の環境を良くする。

## How: チームでミニプロジェクトを回す

* 4〜6人で小規模プロジェクトを立ち上げる
* 実際にツール・イベント・仕組みを作る
* 成果や学びを共有し、次の挑戦者へつなぐ

> 目標は「利益」ではなく「循環」。

[詳細なプロジェクトの内容はこちら](how.md)
